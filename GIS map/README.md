# GIS map – field survey 29 Oct 2026

Cleaned GPS data and map for the SWECC004 oak monitoring site (Wageningen Campus).
Everything in `output/` is regenerated by `build_gis_map.py` from the untouched files in `raw_gpx/`.
Then run `QT_QPA_PLATFORM=offscreen python3 build_qgis_project.py` with the QGIS Python (3.34). It writes the QGIS project and stores the layer styles in the GeoPackage. Run it after every `build_gis_map.py` run, because that script rewrites the GeoPackage.

**Other GIS software (ArcGIS Pro and others):** add `swecc004_field_map.gpkg` directly. All layers are in RD New (EPSG:28992); add a basemap from the software's own catalogue.

## Cleaning applied
1. **g01 pond:** deleted the 2 track points at 13:39:57Z (jumps of 33.5 m and 20.5 m next to waypoint "g01_v10 – glitch"). Also deleted the point at 13:39:59Z. Once the 2 jumps were gone, this ~1 m back-step made the outline cross itself, which gave an invalid polygon.
   Also removed 18 pond-outline vertices where the walk detoured onto the bridge (path1 crosses the pond). The west end has 6 points (13:38:34–13:39:07, around waypoints v06–v08) and the east end has 12 (13:42:01–13:43:28, around v12–v15). All lie within 5 m of path1. The pond edge now runs straight across both bridge ends.
   Also removed the south-east lobe at the start of the pond walk: 28 points from 13:35:36 to 13:36:41, which run from the start point via v02 and v03 to just before v04. The east edge now runs straight from the finish point (v16) down to v04.
   Then removed the corner left behind there: 4 points from 13:36:43 to 13:37:00, which are v04 and a ~4 m dip south. The east edge now runs straight from the finish point (13:44:40) to v05 (13:37:02).
2. **Trees:** kept only the waypoints (Type = WPT): t01–t16. The 147 track points (2 segments, including the GPS wobble near Forum) were dropped.
3. **g03:** deleted the stray waypoint "2:56:04 PM" (lat 51.98414, lon 5.66517, about 150 m south of the lawn). The g03 polygon is built from its track only.
4. **IDs** follow the file names: `g01`–`g07`, `path1`–`path4`, `t01`–`t16`. The printed form uses different numbering. Fill `form_id_on_paper` in the template before joining attributes.
5. **Extent** is computed from all features, so it includes g02, g07 and path4.
6. **Tree measurements (Arboreal):** `raw_measurements/Measurements Arboreal.csv` and its 16 photos are joined to the tree points on ID (T01 → t01). The script checks each match:
   - The Arboreal time (local, UTC+1) is within 3 minutes of the GPS waypoint time.
   - The Arboreal tree centre is nearest to the tree with the same ID, and within GPS accuracy of it.

   The GPS waypoint is kept as the position; the Arboreal coordinates are stored as `arboreal_lat`/`arboreal_lon`, with the distance between the two in `offset_arboreal_m`.
   - **Fields added:** `species`, `height_m` (perpendicular height), `dbh_cm`, `breast_height_m`, `inclination_deg`, `arboreal_time_local`, `arboreal_accuracy_m`, `photo` (`photos/…jpg`, relative to `output/`) and `qa_note`.
   - **Not added:** the crown and CAI columns, because they are empty in the export, and Arboreal's internal AR marker coordinates. Both stay in the raw CSV.
   - **Typo fixed:** "Lach unknown (larix spec.)" → "Larch unknown (Larix spec.)".
   - **QA notes:**
     - t05: Arboreal GPS accuracy was 20.8 m, and its position is 18 m from the waypoint, so the waypoint position is used.
     - t07: a height of 38.1 m is implausible for a silver birch with a 30.7 cm DBH; this tree should be re-measured.

Polygons are built from the walked track (track points), not from the g01 vertex waypoints.

## Study area description
The surveyed area covers about 370 m × 317 m on Wageningen Campus:
- RD New: x 173 996–174 366, y 444 007–444 323
- WGS84 (survey extent with its 10 m margin): lat 51.98403–51.98707 N, lon 5.66358–5.66927 E

It contains:
- 7 mapped habitat polygons:
  - g01 pond (6 898 m²)
  - g02 gravel (2 362 m²)
  - g03 mostly mowed (7 774 m²)
  - g04 Orion (8 052 m²)
  - g05 unmowed shrubs (8 213 m²)
  - g06 Atlas, unmowed (11 360 m²)
  - g07 unmowed trees/shrubs (2 063 m²)
- 4 walked paths (path1 294 m, path2 100 m, path3 280 m, path4 192 m)
- 16 trees (t01–t16), measured with Arboreal. Species: Norway maple, silver birch (2), wild cherry, weeping willow (t06), Salix × sepulcralis (t04, the botanical name for weeping willow, so the species names could be harmonised), larch, hawthorn, ash (2), sweet gum, Caucasian wingnut, bald cypress, cotoneaster and basswood (2)

g02, g07 and path4 lie in the south-west corner of the survey, outside the originally planned area. They are part of the study area, and so are trees t01 and t02 (inside g02) and t03 (inside g07).

## Notes / limitations
- Areas come from phone GPS (accuracy ≈ 3–5 m), so treat them as approximate.
- Small boundary overlaps where neighbouring polygons were walked along the same edge: g05/g06 57 m², g03/g06 17 m², g02/g07 2 m². These were left as recorded.
- The g01 track runs about 70 m further north than the g01 waypoints (no waypoint v11 between v10 and v12). It is a continuous walking-pace track, so it has been kept.
