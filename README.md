# SWECC004 — Oak Tree Health Monitoring

Raw data, R analysis code, and the monitoring plan supporting the SWECC004
study of pedunculate oak (*Quercus robur*) at Natuurbegraafplaats Huis ter
Heide, De Moer, the Netherlands. The study evaluates whether bokashi soil
amendment changes the mineral and biological profile of oak leaves and soil,
comparing three bokashi-treated trees (FT01–FT03), three untreated trees
(NFT04–NFT06), and one healthy reference tree (HT07).

## Contents

- **SWECC004 Monitoring Plan.pdf** — the project monitoring plan that the field and laboratory protocols operationalise
- **Leaf nutrient analysis/** — MP-AES leaf elemental data and calibration script
- **Chlorophyll analysis/** — UV-Vis chlorophyll data, equations, and analysis
- **PhotoFolia analysis/** — PhotoFolia colour readings matched to spectrophotometer chlorophyll
- **Soil analysis/** — soil pH, Hach-Lange nutrients, MP-AES minerals, fungal diversity, earthworms, water content, infiltration
- **Visual crown assessment/** — crown defoliation, transparency, and dieback scores
- **Comparison analysis/** — integrated per-tree dataset combining all indicators

Each analysis folder contains the description `.pdf`, figures in `.jpn`, the  raw `.csv` data, and the `.R` script used to process it.
